## 🚀 COMO USAR AGORA

### 1️⃣ Iniciar o Servidor
```bash
npm start
```

### 2️⃣ Escolher Plataforma
- Android: `npm run android`
- iOS: `npm run ios`
- Web: `npm run web`
- Expo Go: Escanear QR code

### 3️⃣ Jogar Quiz
1. Clique "INICIAR QUIZ"
2. Responda 12 perguntas
3. Veja seu resultado com mensagem personalizada
4. Clique "JOGAR NOVAMENTE" para recomeçar
